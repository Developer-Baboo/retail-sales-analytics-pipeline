# Retail Sales Analytics Pipeline (SQL Server + Python + Excel + Power BI + AI)

End-to-end data project: messy sales data goes through a Python ETL into a **SQL Server star schema**,
is checked by automated **data-quality tests**, and is delivered as an **Excel report**, a **Power BI
dashboard** and an **AI-assisted executive summary**.

> All data is synthetic (generated by `src/generate_data.py`). No real customer data is used.

## Architecture
```
raw CSV (messy) -> Python/pandas clean & validate -> etl.stg_sales (SQL Server staging)
   -> etl.usp_load_star_schema (MERGE upserts) -> dw star schema (fact_sales + 4 dimensions)
   -> OLAP views (ROLLUP, CUBE, window functions) -> Power BI / Excel / AI summary
```

## What it demonstrates
| Skill | Where |
|---|---|
| T-SQL, SSMS, stored procedures, MERGE, transactions, TRY/CATCH | `sql/04_stored_procedures.sql` |
| Star-schema / OLAP modelling, ROLLUP, CUBE, LAG, RANK, window functions | `sql/02`, `sql/05` |
| Indexing (covering + optional columnstore) | `sql/03_indexes.sql` |
| ETL: extract, clean, transform, load, idempotent re-runs | `src/etl.py` |
| Data cleaning (duplicates, nulls, casing, mixed date formats, outliers) | `src/etl.py`, `src/generate_data.py` |
| Data quality checks and run logging | `src/data_quality.py`, `etl.run_log` |
| Excel reporting (live formulas, charts, conditional formatting) | `src/excel_report.py` |
| AI automation (LLM-written summary with safe fallback) | `src/ai_report.py` |
| Power BI model, DAX, dashboard | `powerbi/POWERBI_GUIDE.md` |

## Quick start (no database needed: SQLite demo)
```bash
pip install -r requirements.txt
python run_pipeline.py
```
Outputs land in `output/` (Excel report + executive summary). See `sample_output/` for an example run.

## Run on SQL Server
1. In SSMS run `sql/01` to `sql/05` in order.
2. Copy `.env.example` to `.env` and set `DB_URL` (needs ODBC Driver 17/18).
3. `python run_pipeline.py`. Staging is loaded and `etl.usp_load_star_schema` builds the star schema.
4. Connect Power BI / Excel to `RetailDW` (see `powerbi/POWERBI_GUIDE.md`).

## AI summary (optional)
Set `ANTHROPIC_API_KEY` in `.env` to have an LLM write the executive summary from computed KPIs
(the prompt forbids inventing numbers). Without a key a rule-based summary is produced.

## Sample run results
- 20,150 raw rows -> 150 duplicates and 50 invalid rows removed, 40 discounts capped -> 19,950 fact rows
- 10 automated data-quality checks, all passing
